# Public interface

`index.html`, `style.css`, `app.js`, and `interview.js` are the public frontend sources. The Pages build packages them with real language logos, 116 prepared lessons, and 40 original JavaScript challenges from `content/`. Practice has search, difficulty filters, and saved problems. Interview preparation has eight pattern guides, four company prep paths with real marks, and timed two problem rounds with saved drafts and a results report. Company paths are independently curated themes; they are not claims about actual interview questions or endorsements. Solving a challenge for the first time earns local practice coins by difficulty. The first interview hint is free and the second costs five coins. The browser keeps progress locally and can export or import a backup. Activity streaks count days with completed work. Practice code runs in a sandboxed frame with a three second limit.

The live tutor uses saved lesson notes. AI grading, live Grok responses, cloud accounts, a private judge, and a community leaderboard require server services that GitHub Pages does not provide. `apps/web` currently contains a separate Next.js implementation with Firebase setup and a server based Grok route. It is not the public frontend; those services still need integration with this interface, Firebase configuration, and a server deployment.

The public site links to the [official LeetCode problemset](https://leetcode.com/problemset/) for exact LeetCode questions. Devoal's own question bank is original. It does not copy LeetCode statements, tests, company tags, or their full catalog.
